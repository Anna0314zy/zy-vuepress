# Vue3 源码打包分工（官方脚本）
## 1. 开发环境 dev → 只用 esbuild
- 脚本：`scripts/dev.js`
- 命令：`pnpm run dev`
- 用途：**本地调试、监听热更、极速打包**
- 优势：Go 语言多核并行，**编译极快**，秒级出包
- 输出：未深度压缩、带源码映射，方便断点调试

## 2. 生产打包 build → 主用 Rollup，esbuild 做转译/压缩
- 脚本：`scripts/build.js`
- 命令：`pnpm run build`
- 流程：
  1. TS 先用 **esbuild 快速转译**（TS→JS）
  2. 交给 **Rollup 做多格式打包、极致 Tree Shaking、分包**
  3. 最后再用 esbuild/SWC 做**代码压缩混淆**
- 输出：ESM / CJS / UMD / browser 全格式 npm 包，体积最小、Tree Shaking 最优

---

# 为什么两套搭配（官方原话）
> We are still using Rollup for production builds because it generates smaller files w/ better tree-shaking.
> 开发用 esbuild 快；生产用 Rollup 打包质量、体积、分包、ESM 优化更强

| 工具 | 场景 | 核心优势 |
|---|---|---|
| esbuild | 开发构建、TS转译、压缩 | 速度极快、Go并行、TS原生 |
| Rollup | 库生产打包 | ESM Tree Shaking 最强、多格式规范、插件完善、产物纯净 |

# 闭包 
**定义函数的作用域 和执行函数的作用域不是同一个**
---

## 一句话标准答案
**函数定义时所在作用域 ≠ 函数执行时所在作用域**
=> 产生闭包

---


```js




```

## 拆开讲超好理解
1. **定义作用域**：函数写在哪、在哪诞生
2. **执行作用域**：函数在哪调用、在哪运行

- 正常情况：在哪定义 → 在哪执行
  没有闭包
- 特殊情况：
  函数**在A作用域定义**，跑到**B作用域执行**
  函数依然记得A作用域的变量
  → **闭包诞生**

---

## 对应你那句话的代码
```js
function outer(){
  let a = 10
  function inner(){ // inner 定义在 outer 作用域
    console.log(a)
  }
  return inner
}

const fn = outer() 
fn() // fn 在全局作用域执行
```
- 定义作用域：outer 内部
- 执行作用域：全局 window
**不一样 = 闭包**

---

## 再极简总结
- 词法作用域（定义在哪）**永久绑定**
- 执行作用域（在哪调用）随便变
两者错开 → 闭包

### ✅ 练习题
1.  定义一个函数 `calc_avg`，接收任意多个数字作为参数，返回它们的平均值。
    ```python
    # 示例调用
    print(calc_avg(1,2,3))   # 输出 2.0
    print(calc_avg(5,10,15,20)) # 输出 12.5
    ```

<details>
<summary>查看答案</summary>

```python
def calc_avg(*args):
    if not args:  # 处理空参数的情况
        return 0
    return sum(args) / len(args)
```

## 二、解包（Unpacking）
### 核心知识点
```python
# 列表/元组解包
a, b, *rest = [1, 2, 3, 4, 5]
print(a, b, rest)  # 1 2 [3, 4, 5]

# 字典解包
def print_info(name, age):
    print(f"姓名：{name}，年龄：{age}")

info = {"name": "小红", "age": 18}
print_info(**info)
```

## 三、Lambda 匿名函数
### 核心知识点
```python
add = lambda a, b: a + b
print(add(3,5))  # 8

# 配合高阶函数使用
nums = [1, 2, 3, 4, 5]
even_nums = list(filter(lambda x: x % 2 == 0, nums))
print(even_nums)  # [2, 4]
```

## 四、闭包（Closure）
### 核心知识点
```python
def make_adder(x):
    def adder(y):
        return x + y
    return adder

add5 = make_adder(5)
print(add5(3))  # 8
print(add5(10)) # 15
```

### ✅ 练习题
6.  用闭包实现一个计数器函数，每次调用时计数自动+1，初始值为0。
    ```python
    # 示例调用
    c = counter()
    print(c()) # 1
    print(c()) # 2
    print(c()) # 3
    ```

<details>
<summary>查看答案</summary>

```python
def counter():
    count = 0
    def inner():
        nonlocal count  # 声明count为非局部变量
        count += 1
        return count
    return inner
```
</details>

## 五、装饰器（Decorators）
### 核心知识点
```python
import functools

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"函数 {func.__name__} 执行耗时: {end - start:.4f}秒")
        return result
    return wrapper

@timer
def slow_func():
    import time
    time.sleep(1)
    print("执行完成")

slow_func()
```

### ✅ 练习题
7.  写一个装饰器 `logger`，在函数执行前打印 `[INFO] 开始执行：函数名`，执行后打印 `[INFO] 执行结束：函数名`。
8.  写一个带参数的装饰器 `repeat(n)`，让被装饰的函数重复执行 `n` 次。

<details>
<summary>查看答案</summary>

```python
# 第7题
import functools

def logger(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[INFO] 开始执行：{func.__name__}")
        result = func(*args, **kwargs)
        print(f"[INFO] 执行结束：{func.__name__}")
        return result
    return wrapper

@logger
def hello():
    print("Hello, World!")

hello()

# 第8题
def repeat(n):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def greet():
    print("Hi!")

greet()  # 会打印3次Hi!
```
</details>

## 六、综合练习题
9.  用闭包+装饰器的思路，实现一个带缓存功能的装饰器，缓存函数的执行结果，相同参数调用时直接返回缓存结果（提示：可以用字典存储缓存）。

<details>
<summary>查看答案</summary>

```python
import functools

def cache(func):
    cache_dict = {}
    @functools.wraps(func)
    def wrapper(*args):
        if args not in cache_dict:
            print(f"第一次调用，计算结果...")
            cache_dict[args] = func(*args)
        else:
            print(f"使用缓存结果...")
        return cache_dict[args]
    return wrapper

@cache
def add(a, b):
    return a + b

print(add(1,2))  # 计算并缓存
print(add(1,2))  # 直接使用缓存
print(add(3,4))  # 计算并缓存
```
</details>

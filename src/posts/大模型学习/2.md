# ChatPromptTemplate 实例化「全传参方式」一页速查手册
## 一、两类实例化方式
### 1. 原生构造器（全参数手动传）
```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate(
    messages=[...],                # 必传
    input_variables=[...],         # 选填
    optional_variables=[...],      # 选填
    partial_variables={...},        # 选填
    template_format="f-string",    # 选填
    validate_template=True          # 选填
)
```

### 2. 静态快捷方法（生产99%使用）
自动推导变量、模板格式，无需手动配置
```python
prompt = ChatPromptTemplate.from_messages([...])
```

---

## 二、六大参数 + 合法传参格式
### 1. messages【必传｜核心】
支持**5种混合传入格式**
1. 角色元组（最简）
```python
("system", "你是前端架构师，严格按{rule}输出")
("human", "帮我优化{code}")
("ai", "历史回答内容")
```
2. 原生消息对象
```python
from langchain_core.messages import SystemMessage,HumanMessage,AIMessage
SystemMessage(content="全局规则")
HumanMessage(content="{query}")
```
3. 动态占位符（多轮对话必备）
```python
from langchain_core.prompts import MessagesPlaceholder
MessagesPlaceholder(variable_name="chat_history")
```
4. 嵌套子模板
```python
example_prompt  # 传入另一个 ChatPromptTemplate 实例
```
5. 纯字符串（自动识别为 human）
```python
"简单提问内容"
```

---

### 2. input_variables【选填】
类型：`list[str]`
作用：声明**必填变量**，缺失直接报错
```python
input_variables = ["query", "code", "rule"]
```

### 3. optional_variables【选填】
类型：`list[str]`
作用：声明**可选变量**，不传不报错
```python
optional_variables = ["style", "language"]
```

### 4. partial_variables【选填】
类型：`dict[str, Any]`
作用：提前固化固定变量，局部填充
```python
partial_variables = {"role": "高级前端工程师"}
```

### 5. template_format【选填】
类型：`str` 固定二选一
```python
template_format = "f-string"  # 默认，{var}
template_format = "jinja2"   # 循环/条件，{{var}}
```

### 6. validate_template【选填】
类型：`bool`
```python
validate_template = True   # 校验变量合法性（默认）
validate_template = False  # 关闭校验，适合动态复杂模板
```

## 三、高频完整可运行示例
### 示例1：标准多轮对话（日常开发标配）
```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是{role}，回答简洁专业"),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "用户问题：{question}")
])
```

### 示例2：原生全参数手写（底层学习用）
```python
prompt = ChatPromptTemplate(
    messages=[
        ("system", "严格遵守{limit}要求"),
        ("human", "处理内容：{content}")
    ],
    input_variables=["content"],
    optional_variables=["limit"],
    partial_variables={"limit": "不超过200字"},
    template_format="f-string",
    validate_template=True
)
```

## 四、核心背诵总结
1. 实例化分两种：**原生构造器、from_messages 快捷写法**
2. 唯一必传：`messages`，5种格式自由混搭
3. 变量三类：**必填(input) / 可选(optional) / 固化(partial)**
4. 配置两类：**模板语法、变量校验**
5. 业务开发只用：`ChatPromptTemplate.from_messages`

## 代码

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage

# ====================== 1. 定义模板（你给的全参数写法）======================
prompt = ChatPromptTemplate(
    messages=[
        ("system", "你是{role}，严格遵守{limit}要求"),
        MessagesPlaceholder(variable_name="chat_history"),  # 多轮历史
        ("human", "用户问题：{question}")
    ],
    input_variables=["question"],            # 必填变量
    optional_variables=["chat_history"],    # 可选变量
    partial_variables={                     # 提前固定的变量
        "role": "资深Python工程师",
        "limit": "回答简洁、专业、不超过300字"
    },
    template_format="f-string",
    validate_template=True
)

# ====================== 2. 准备要填充的内容 ======================
# 模拟历史对话（可选，不传也可以）
chat_history = [
    HumanMessage(content="什么是列表推导式？"),
    AIMessage(content="列表推导式是快速生成列表的语法，格式：[x for x in iterable]")
]

# 当前用户问题
question = "那怎么用它过滤偶数？"

# ====================== 3. 最终调用：生成完整对话消息 ======================
final_messages = prompt.format_messages(
    question=question,            # 必传
    chat_history=chat_history     # 可选
)

# ====================== 4. 打印看最终结果（最关键！）======================
print("===== 最终生成给大模型的消息 =====")
for msg in final_messages:
    print(f"[{msg.type}] {msg.content}")

```

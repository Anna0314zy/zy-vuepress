# 一、这张图在讲什么（核心一句话）

👉 **BaseChatMessageHistory = 聊天记录存储的抽象接口**

# 二、拆解图里的几个关键点

## 1️⃣ BaseChatMessageHistory 是啥？

可以理解为：

```text
聊天记录数据库的接口（抽象类）
```

它定义了：

### 属性

```python
messages: List[BaseMessage]
```

👉 当前所有聊天记录（只读）

---

### 方法（重点）

#### 1. add_message

```python
add_message(message)
```

👉 添加一条消息（你必须自己实现）

---

#### 2. add_messages

```python
add_messages(messages)
```

👉 批量添加（默认帮你循环调用 add_message）

---

#### 3. clear

```python
clear()
```

👉 清空聊天记录

---

⚠️ 注意：
你**必须自己实现**：

* add_message
* clear

否则会报错

# 五、完整使用流程（你一定要掌握）

我给你一个最小可运行思路👇

---

## 1️⃣ 定义一个 memory

```python
from langchain.memory import ChatMessageHistory

store = {}

def get_session_history(session_id):
    if session_id not in store:
        store[session_id] = ChatMessageHistory()
    return store[session_id]
```

---

## 2️⃣ 包装 Runnable

```python
from langchain_core.runnables.history import RunnableWithMessageHistory

chain_with_memory = RunnableWithMessageHistory(
    chain,
    get_session_history,
    input_messages_key="input",
    history_messages_key="history",
)
```

---

## 3️⃣ 调用（关键）

```python
chain_with_memory.invoke(
    {"input": "你好"},
    config={"configurable": {"session_id": "user1"}}
)
```

---

👉 第二次：

```python
chain_with_memory.invoke(
    {"input": "我刚才说了什么？"},
    config={"configurable": {"session_id": "user1"}}
)
```

👉 这时候模型就“记住了”

> Embedding = 把文本变成向量，通过“距离”判断相似度

关键点只有两个：

```text
1. 文本 → 向量
2. 向量之间可以算距离
```

---

# 二、这个“距离”到底怎么算？（核心）

最常用的是 **余弦相似度** 👇

\cos(\theta) = \frac{A \cdot B}{|A||B|}

你可以这样理解：

* 两个向量方向越接近 → 越相似
* 完全一样 → 1
* 完全无关 → 0

👉 注意：不是看“长度”，而是看“方向”

你截图列了一堆：

* 搜索

其实本质可以压缩成两件事：

## 1️⃣ 找相似（Search / 推荐 / 分类）

```text
输入 → 找最像的
```

比如：

```text
“AI课件怎么做？”
```

→ 找最像的课件内容

---

## 2️⃣ 看分布（聚类 / 异常检测）

```text
看一堆向量之间的关系
```

比如：

* 哪些课件是同一类？
* 哪个内容“很奇怪”（离群点）

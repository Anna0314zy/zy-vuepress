## 1. 可选 bullet（按真实参与度取舍）

### Monorepo 与契约治理

- **主导**基于 pnpm workspace 的课件工程拆分，将页面 DSL 收敛至 `@icw/schema` + `@icw/typing`，实现 **运行时校验 + 多版本迁移**（`updateToLatest`），降低播放器与编辑器 **协议漂移** 导致的线上故障。
- 设计并落地 **版本区间归约** 策略，使历史课件资产可平滑升级至最新 schema；推动 descriptor / typing / migration **同城变更** 的 CR 规范。

### 编辑器架构

- 基于 **Rematch + Immer** 重构编辑内核状态，抽象 `main` 等业务 model；通过 Redux **中间件实现自动持久化**（`realTimeSave`），将保存策略从组件副作用 **收敛为横切关注点**。
-（若做过）优化自动保存 **debounce / 竞态处理**，使保存 QPS 下降 X%，冲突率下降 Y%（填实测）。

### 运行时与引擎

- 推动 **编辑器与渲染进程解耦**，独立交付 `cocos-render` / `se-render`，通过消息协议连接 `@powercourse/render-engine-cocos2` 与 `@powercourse/game-sdk`，实现引擎升级 **不影响** 编辑主路径稳定性。
- 参与 Player V2 与 **教室 Bridge / JSON-RPC** 集成，封装宿主能力与播放器沙箱边界，支撑课堂 **设备与权限** 扩展。

### 云与转码

- 负责 `sl-conversion` Serverless 链路：**esbuild 打包 + 腾讯云 SCF**，拆分 PPT/PDF/打包等 handler；设计 **taskUUID 幂等与失败回调**（`notifyConversionResult`），并串联 **Lark 告警** 缩短 MTTR。
-（若做过）将同步长任务改造为 **异步任务 + 回调**，云函数超时率下降 X%。

### 质量与基建

- 引入 **Sentry** 多端监控与 release 标记；推动 patch-package 补丁 **ADR 化** 与依赖升级窗口。
-（若做过）搭建 affected build / 缓存策略，PR 构建耗时下降 X%。

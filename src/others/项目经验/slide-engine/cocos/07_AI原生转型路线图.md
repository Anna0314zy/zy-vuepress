# AI 原生转型路线图

> 「AI 原生」在此定义为：将 **大模型能力、检索增强、智能体编排、评测闭环** 以 **一等公民契约** 嵌入现有课件 DSL、编辑器工作流与播放器观测链路，而非外挂聊天框。

## 0. 现状锚点（与 AI 相关的已有线索）

- **ASR**：根依赖含 `@classpod/asr-web`，说明业务已触及 **语音转写** 场景，具备接入实时字幕、口述出题等能力的基建切口。
- **OCR**：编辑器依赖 `@paddlejs-models/ocr`，已有 **端侧视觉理解** 路径，可演进为「板书识别 → 结构化组件插入」。
- **结构化内容**：`@icw/schema` 提供强类型课件树，是 **LLM 输出 grounding** 的理想靶结构（比自由 HTML 更易校验与回滚）。

## 1. 阶段一：契约层 AI-ready（0–2 个月）

**目标：** 让 AI 产出 **可校验、可迁移** 的课件片段，而非裸 JSON。

**动作：**

1. 定义 **`AIGeneratedPatch` 子协议**：包含 `targetPageVersion`、`ops[]`、`confidence`、`evidenceRefs`（引用素材 ID 或用户选区）。
2. 所有 AI 产出经 `@icw/schema.validate` + `updateToLatest` 双闸门；失败时 **结构化反馈** 给模型复写。
3. 在 `typing` 中增加 **溯源字段**（可选）：`provenance: { source: 'human' | 'ai', model?: string, promptHash?: string }`，支撑合规审计。

**验收：** 线上灰度「生成一页课件」任务中，校验失败率可度量且可自动重试。

## 2. 阶段二：编辑器 Copilot 与工作流编排（2–5 个月）

**目标：** AI 进入 **Rematch action/command** 层，而非直接操控 DOM。

**动作：**

1. 引入 **Command Bus**：`SuggestCommand` → 人类确认 → `CommitCommand` 派发 Redux action；禁止模型直接调用私有 reducer。
2. **RAG**：课件组件库、校本题库、品牌模板入库向量索引；检索上下文 **按 icwCode / pageId 分区**，防止串租户。
3. **工具调用（function calling）**：封装「插入组件」「替换资源」「批量改题干」等原子工具，映射到现有 services。

**验收：** 人类可在 diff 面板审查 AI 变更；一键回滚到 `provenance` 之前快照。

## 3. 阶段三：播放器侧智能反馈闭环（3–6 个月）

**目标：** 将 **学习行为信号** 回流模型训练与课件迭代。

**动作：**

1. 与 `@classpod/classroom-bridge` 对齐 **匿名化遥测事件**（停留时长、交互失败、音频卡顿标记）。
2. 构建 **Fine-tuning / Preference data** 流水：同一课件版本的 A/B 交互对比。
3. 异常检测：结合 Sentry 事件与课堂日志，自动打开「AI 根因摘要」供值班工程师处理（内部运维 Copilot）。

**验收：** 指标仓库可回答「哪类 Widget 在何种网络下失败率升高」并被 AI 摘要。

## 4. 阶段四：Agentic 创作与多角色协同（6–12 个月）

**目标：** 「课件项目经理」Agent 拆解教学目标 → 调用模板引擎 → 人类在关键节点把关。

**动作：**

1. **多 Agent 分工**：编剧 Agent（教学目标）、视觉 Agent（布局）、测评 Agent（出题与标答）、合规 Agent（版权与敏感词）。
2. **长事务**：与 `sl-conversion` 联动，Agent 触发资源导入任务并异步等待 manifest。
3. **人在回路（HITL）**：高风险操作（发布、全量替换资产）强制人工 gate。

## 5. 风险与非功能需求

| 风险 | 缓解 |
|------|------|
| 幻觉组件 ID | Schema 校验 + 只允许注册表内 widget 类型 |
| 隐私与未成年人合规 | 数据分区、最小留存、校内私有化推理网关 |
| 成本失控 | 缓存 prompt、检索裁剪 token、端侧小模型做多级漏斗 |
| 与旧 Webpack 栈耦合 | AI SDK 独立 micro-frontend 或 iframe，隔离构建 |

## 6. 里程碑小结

1. **契约 AI 化**（ Schema 闸门 + 溯源）。
2. **编辑器可控 Copilot**（Command Bus + RAG）。
3. **课堂数据闭环**（Bridge + 观测）。
4. **多 Agent 流程**（异步任务与人类 gate）。
